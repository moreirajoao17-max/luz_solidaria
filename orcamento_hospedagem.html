Justificativa da escolha

  • Railway é a hospedagem usada na disciplina e publica o site sozinha a cada push na branch main do GitHub, com HTTPS automático.
  • É a única das três que já permite um back-end com banco MySQL, que poderá guardar as mensagens do formulário no futuro.
  • Para o projeto acadêmico, o Trial e o plano Free bastam, então o custo agora é zero.
  • Quando a ONG tiver CNPJ, o domínio luzsolidaria.org.br é o mais adequado e custa R$ 40 por ano, sem aumento na renovação.
  • Sustentabilidade: reduzimos o peso das imagens de cerca de 16 MB para 2,6 MB, o que gasta menos dados e menos energia a cada visita. Antes de contratar, a equipe vai conferir se o provedor usa energia renovável no Green Web Foundation.
